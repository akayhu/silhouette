# 片刻剪趣 — 線上短影音剪輯網站

好上手的線上短影音剪輯工具，淺色介面，含會員登入與訂閱（免費版／專業版 NT$399／月）。

## 啟動

```bash
npm install
npm run dev
```

打開 http://localhost:5173 。`npm run dev` 會同時啟動前端（Vite，5173）和後端 API（Node，8787）。

|---|---|
| 會員 | Email＋密碼註冊／登入、修改名稱與密碼。Google 登入按鈕已放好，需設定 OAuth 用戶端 ID 才能使用 |
| 訂閱 | 免費版：每月 3 個專案、720p、浮水印；專業版：不限專案、1080p、無浮水印、AI 功能。目前是**本機模擬付款**（不會扣款），可取消／恢復訂閱、有付款紀錄 |

## 管理後台

網址：`/admin`（只有管理者帳號能進入，一般會員會被導回自己的專案頁）

- **總覽**：會員總數、付費／免費人數與比例、累計總營收、今日營收；每日付費金額長條圖、累計總金額折線圖、每日新增會員（可切換近 7／30／90 天，也能以表格檢視）
- **會員管理**：搜尋、依付費／免費篩選；可直接為會員開通專業版（1／3／6／12 個月或永久，不計入營收）、取消付費、刪除帳號（需輸入 Email 確認；付款紀錄保留）

建立管理者帳號（已存在的會員會被升級為管理者）：

```bash
npm run create-admin -- --email admin@example.com --name 管理者
```

沒有指定 `--password` 時會自動產生密碼，寫在 `server/data/admin-credentials.txt`（不會上傳 GitHub）。

示範資料（讓圖表有資料可看，只用在本機）：`npm run seed-demo` 產生、`npm run seed-demo -- --clean` 移除。示範會員的 Email 都是 `@demo.silhouette.test`。

## 台灣腔 AI 人聲（BreezyVoice）

朗讀的「台灣腔 AI 人聲」使用聯發科開源的 [BreezyVoice](https://github.com/mtkresearch/BreezyVoice)，在這台電腦上執行，不需帳號、不送資料到外部。

- 安裝（約 3 GB，只要一次）：`./scripts/setup-ai-voice.sh`
- 沒安裝時，朗讀面板只會顯示 macOS 系統語音，其他功能不受影響
- 內建聲音：曉涵（台灣腔女聲）。使用者可以錄一段約 10 秒的朗讀「建立我的聲音」，每人最多 10 個
- 速度：在 M1／8GB 上每句約 30–60 秒，第一次使用要多等約 20 秒載入模型；閒置 10 分鐘後自動關閉以釋放記憶體
- 程式位置：`tts/service.py`（常駐服務，埠號 8790，由 API 伺服器自動啟動）、`tts/voices/`（內建聲音）、`tts/shims/`（取代 macOS 裝不起來的中文正規化套件）

## 音樂庫

音樂庫的曲目由 `scripts/generate-music.mjs` 用程式合成（原創、無版權），輸出到 `server/music/`，清單在 `server/music/library.json`。重新產生：

```bash
node scripts/generate-music.mjs
```

想加入自己找的無版權音樂（例如 CC0 授權）：把 `.m4a` 或 `.mp3` 放進 `server/music/`，再到 `library.json` 的 `items` 加一筆（`id`、`title`、`category` 填 `music` 或 `sfx`、`mood`、`duration`、`url`、`peaks` 可填空陣列）。注意重新執行產生腳本會覆蓋 `library.json`。

## SEO 與正式部署

```bash
SITE_URL=https://你的網域 npm run build   # 或在 .env 設定 VITE_SITE_URL（參考 .env.example）
npm run server                              # 同一個服務提供 API 和建置好的網站
```

- 首頁和價格頁會在建置時預先產生成靜態 HTML（`scripts/prerender.mjs`），搜尋引擎不執行 JavaScript 也讀得到標題、描述、內文和連結
- 每頁的標題、描述集中在 `src/lib/seo.ts`；登入後的頁面、登入頁和 404 都會加上 noindex
- 首頁含結構化資料（WebApplication 方案價格、FAQPage），內容和頁面上看得到的一致
- 設定 SITE_URL 後才會輸出 canonical、og:url 和 `sitemap.xml`，並在 `robots.txt` 加上 Sitemap
- 不存在的網址回傳 HTTP 404；如果改用其他靜態主機，SPA 的備援頁請指向 `dist/app.html`，不要指向 `index.html`
- 分享預覽圖：`public/og-image.png`（1200×630）

## 匯出驗證

執行 `npm run dev` 後，開啟 `/tests/export.html` 並按「執行全部測試」。測試頁只由開發伺服器提供，不會包含在正式建置中；使用程式產生的素材，不需要帳號或存取使用者資料。

涵蓋實際錄製與解碼、音訊內容、尾端畫面、修剪與轉場／疊加、素材錯誤、準備／錄製取消、MP4 到 WebM 備援、錄製器錯誤、背景中止、5 秒試匯出，以及串流／音訊資源釋放。

匯出仍採瀏覽器即時錄製，請保持分頁在前景。MP4 是否可用依瀏覽器編碼器而定，不會將 WebM 更名為 MP4。尚未導入伺服器編碼或逐幀匯出。

## 儲存與復原

- 編輯後約 1.2 秒自動同步，單一分頁同時只送出一個儲存請求；儲存期間繼續編輯，不會被舊回應標示為已同步。
- 編輯期間約每 150ms 將最新草稿寫入 IndexedDB。切換背景、離開或重新整理時，另嘗試以 localStorage 寫入緊急備份。備份依帳戶、專案與編輯工作階段隔離。
- 暫時失敗會退避重試，最多自動重試五次；恢復連線與「立即重試」可重新啟動。登入過期、版本衝突與專案不存在等錯誤不會持續自動重送。
- 重新開啟專案時，先提供未同步草稿的選擇。若伺服器也有更新，復原後暫停同步，需明確選擇保留的版本。
- 編輯器連結與瀏覽器返回會提示未同步修改；重新整理／關閉時使用瀏覽器內建提醒（瀏覽器或作業系統強制終止時不保證觸發）。本機空間不足或權限停用時會顯示備份失敗。
- 可下載 JSON 草稿備份。草稿包含時間軸、字幕、效果、專案名稱與素材網址，不包含原始影音檔，也不是伺服器的歷史版本備份。清除網站資料會一併清除本機草稿。

測試：`node --test tests/persistence-api.test.mjs` 使用暫存資料庫測試伺服器版本檢查，不接觸既有會員資料。`npm run dev` 後開啟 `/tests/persistence.html` 可執行瀏覽器的儲存、離線、復原及導航測試；測試頁不包含在正式建置中。

## 字幕校對與批次編輯

「字幕」面板現在以校對列表為主：

- 純文字搜尋與批次取代，英文可切換大小寫；操作範圍可選目前搜尋列表（含其他頁）、勾選字幕或全部。
- 預設排除智能剪輯的花字，可勾選「包含花字」。每頁顯示 25 句，批次處理仍涵蓋完整範圍。
- Enter 跳到下一句並定位預覽，Shift+Enter 換行，⌘／Ctrl+Enter 或「依游標拆句」會同時分開文字與時間。拆句依字數估算時間，並非逐字語音對齊；可在時間欄位微調。
- 合併相鄰勾選字幕時保留換行、沿用第一句樣式；字幕間空白也會包含在合併後的顯示區間。
- 每句可輸入秒數或 `00:00:01.250` 調整時間；批次平移正數延後、負數提前，若早於零點或超出 99 小時則整批拒絕。也可批次套用樣式。
- 專案校正字典每行使用「錯字 => 正確詞」，可儲存人名、品牌等規則，並手動套用至指定範圍。字典隨專案同步與草稿備份；同一次操作不會連鎖取代新產生的詞。
- 支援 UTF-8 的 SRT／WebVTT 匯入匯出。匯入先顯示預覽，可追加或取代一般字幕（保留花字）；錯誤檔案不會部分寫入。檔案上限 2 MB、10,000 句。匯入的標記與位置設定轉為純文字，匯出保留時間與換行，不包含視覺樣式。
- 修改、合併、拆句、批次處理和匯入皆可透過編輯器復原／重做，並接回自動儲存。字幕軌鎖定時停止所有編輯操作，仍能匯出字幕檔。

測試：`node --test tests/captions.test.mjs`（Node 24），以及開發伺服器的 `/tests/captions.html`。瀏覽器測試只使用程式產生的字幕，不存取會員資料。
