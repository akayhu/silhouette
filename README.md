# 片刻剪趣 — 瀏覽器裡的繁體中文短影音剪輯

打開瀏覽器就能剪短影音：把手機拍的影片拖進來，自動剪掉空拍、上好繁體中文字幕，再依內容加上特寫、轉場和動畫，挑版本、微調後就能匯出 MP4。

- **本機優先**：影片、圖片、音樂只存在使用者電腦的瀏覽器裡，不上傳到伺服器；帳戶只存專案（剪輯內容、字幕、設定）。
- **在瀏覽器裡跑 AI**：語音辨識（Whisper）、翻譯、逐格匯出都在瀏覽器完成。
- **會員與訂閱**：免費版（每月 3 個專案、720p、浮水印）／專業版 NT$399／月（不限專案、1080p、無浮水印、AI 功能）。新會員註冊送 7 天專業版。

## 快速開始

需要 **Node.js 24** 以上（後端使用內建的 `node:sqlite`，測試使用 Node 的 TypeScript 型別剝除）。建議使用最新版 Chrome 或 Edge。

```bash
npm install
npm run dev
```

打開 http://localhost:5173 。`npm run dev` 會同時啟動前端（Vite，5173）和後端 API（Node，8787），前端的 `/api` 會轉送到後端。

第一次使用請到 `/register` 註冊帳號；要測試管理後台，見下方「管理後台」建立管理者。

## 本機優先：素材存放方式

- 使用者加入的影片、圖片、音樂存在瀏覽器的 IndexedDB（資料庫名稱 `pianke-media`），並向瀏覽器申請持久儲存。
- 專案存到帳戶時，素材網址記成 `local:素材 id`，另外記下檔名、大小與類型；打開專案時再換回這台裝置上的檔案。
- **換裝置或清除瀏覽器資料後，需要重新提供素材**：素材庫會顯示「這台裝置找不到 N 個素材」，選回原本的檔案就會依檔名和大小自動配對。
- 伺服器不接收素材上傳。改版前上傳到伺服器的舊素材，素材庫會提供「移到這台裝置」；專案存檔時，伺服器會刪掉專案資料夾裡不再使用的檔案（保留 10 分鐘內新產生的）。
- 文字朗讀在伺服器產生，前端拿到後存到本機。
- 素材面板會顯示這台裝置已使用的空間；刪除專案時一併清除本機檔案。

仍存在伺服器上的：專案資料（SQLite）、自訂聲音的錄音樣本、使用者選擇「存到帳戶」的匯出成品，以及還沒移到本機的舊素材。

## 儲存與復原

- 編輯後約 1.2 秒自動同步；同時另寫一份草稿到 IndexedDB，切到背景或離開時再以 localStorage 做緊急備份。
- 暫時失敗會退避重試（最多 5 次）；登入過期、版本衝突、專案不存在不會一直重送。
- 重新開啟專案時，先提供未同步草稿的選擇；伺服器也有更新時，需要明確選擇保留哪個版本。
- 可下載 JSON 草稿備份（含時間軸、字幕、效果與素材資訊，不含原始影音檔）。

## 管理後台

網址 `/admin`，只有管理者帳號能進入。

- **總覽**：會員數、付費比例、營收，以及每日付費、累計金額、新增會員圖表（近 7／30／90 天，可切換表格）。
- **會員管理**：搜尋、篩選、開通專業版（不計入營收）、取消付費、刪除帳號（付款紀錄保留）。

建立管理者（已存在的會員會被升級）：

```bash
npm run create-admin -- --email admin@example.com --name 管理者
```

沒有指定 `--password` 時會自動產生，寫在 `server/data/admin-credentials.txt`（已排除在 Git 之外）。

示範資料（只用在本機，讓圖表有資料）：`npm run seed-demo` 產生、`npm run seed-demo -- --clean` 移除。示範會員的 Email 都是 `@demo.silhouette.test`。

## 台灣腔 AI 人聲（BreezyVoice）

使用聯發科開源的 [BreezyVoice](https://github.com/mtkresearch/BreezyVoice)，在本機執行。

- 安裝（約 3 GB，只要一次）：`./scripts/setup-ai-voice.sh`
- 沒安裝時，朗讀只會顯示 macOS 系統語音，其他功能不受影響。
- 使用者可以錄一段約 10 秒的朗讀「建立我的聲音」，每人最多 10 個（請只用自己或已取得同意的聲音）。
- 速度：M1／8GB 每句約 30–60 秒；閒置 10 分鐘後自動關閉。
- 程式位置：`tts/service.py`（埠號 8790，由 API 伺服器自動啟動）、`tts/voices/`、`tts/shims/`。

## 音樂庫

曲目由 `scripts/generate-music.mjs` 用程式合成（原創、無版權），輸出到 `server/music/`，清單在 `server/music/library.json`：

```bash
node scripts/generate-music.mjs
```

要加入自己找的音樂（請確認授權允許商用與放進工具裡使用，例如 CC0）：把 `.m4a`／`.mp3` 放進 `server/music/`，再在 `library.json` 的 `items` 加一筆（`id`、`title`、`category` 填 `music` 或 `sfx`、`mood`、`duration`、`url`、`peaks`）。重新執行產生腳本會覆蓋 `library.json`。

## 專案結構

```
src/
  pages/        首頁、價格、登入註冊、我的專案、帳戶、管理後台
  editor/       編輯器（時間軸、預覽、屬性、各工具面板、引導、封面、匯出視窗）
  lib/          引擎（engine）、匯出（exportVideo／offlineExport／frameDecoder）、
                本機素材（localMedia）、語音辨識（asr）、字幕（captions／scriptAlign／captionCheck）、
                翻譯（translate）、時間軸操作（timeline）…
server/
  index.mjs     API（會員、訂閱、專案、匯出成品、朗讀、管理後台）
  music/        原創配樂與音效
  data/         SQLite 資料庫與伺服器端檔案（已排除在 Git 之外）
scripts/        建立管理者、示範資料、音樂產生、預先產生 SEO 頁面、安裝 AI 人聲
tests/          Node 單元測試與瀏覽器測試頁
```

資料位置：資料庫 `server/data/app.db`、伺服器端檔案 `server/data/uploads/`（朗讀結果、自訂聲音、存到帳戶的匯出成品、舊素材）。刪掉 `server/data` 即可重置伺服器資料；使用者的本機素材在各自的瀏覽器裡。

## 測試

```bash
npm run typecheck
node --test tests/*.test.mjs
```

Node 測試涵蓋字幕批次編輯、逐字時間與文字剪輯、裁剪、講稿對時、字幕品質檢查、雙語字幕，以及伺服器的專案版本檢查（使用暫存資料庫，不接觸既有資料）。

瀏覽器測試頁（只在 `npm run dev` 時提供，不會包含在正式建置中，只使用程式產生的素材）：

- `/tests/captions.html`：字幕面板的校對與批次操作
- `/tests/persistence.html`：儲存、離線、復原與導航
- `/tests/export.html`：匯出（以即時錄製路徑為主）

## SEO 與正式部署

```bash
SITE_URL=https://你的網域 npm run build   # 或在 .env 設定 VITE_SITE_URL（參考 .env.example）
npm run server                              # 同一個服務提供 API 和建置好的網站
```

- 首頁、價格頁在建置時預先產生靜態 HTML（`scripts/prerender.mjs`），搜尋引擎不執行 JavaScript 也讀得到內容。
- 每頁的標題、描述集中在 `src/lib/seo.ts`；登入後的頁面、登入頁和 404 加上 noindex。
- 首頁含結構化資料（WebApplication 方案價格、FAQPage），內容與頁面一致。
- 設定 `SITE_URL` 後才輸出 canonical、og:url、`sitemap.xml`，並在 `robots.txt` 加上 Sitemap。
- 不存在的網址回傳 HTTP 404；改用其他靜態主機時，SPA 備援頁請指向 `dist/app.html`。
- 分享預覽圖：`public/og-image.png`（1200×630）。

## 上線前要補的

- **金流**：把 `/api/billing/checkout` 換成正式金流（目前是本機模擬付款，不會扣款）。
- **Google 登入**：設定 OAuth 用戶端 ID。
- **文字朗讀**：系統語音依賴 macOS 的 `say`；部署到 Linux 需改用其他語音引擎或雲端 TTS。
- **音樂、字型等公開檔案**：使用者變多時建議放 CDN，減少主機流量。
- **舊素材清理**：決定伺服器上舊素材的保留期限。
